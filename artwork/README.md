# 小酌场 / SipSession 原稿

Simmons 交付的源文件。处理后的 App 资源在 `DrinkTrack/DrinkTrack/Assets.xcassets/`，用法见那边的 `ARTWORK.md`。

| 文件 | 用途 |
| --- | --- |
| `drinktrack-logo-icon-1024.png` | 1024×1024、RGB、无透明、无预切圆角。用作 App 图标。 |
| `drinktrack-logo-icon-512.png` | 同一标志的 512×512 版本，备用。 |
| `drinktrack-splash-portrait.jpg` | 竖屏开屏参考稿（720×1280）。实际开屏是按此合成的更高清图，不是直接放大这张 JPG。 |
| `drinktrack-splash-landscape.jpg` | 横屏开屏参考稿（1280×720）。 |
| `drinktrack-lockup.jpg` | 白底锁头图（图标已带圆角）。只用在引导页 / 关于页，不能当 App 图标。 |
| `drinktrack-icon-cheers.jpg` | 同一标志，但已经预切圆角。只作参考，禁止替换 `AppIcon.png`，否则系统会再加一层圆角。 |
